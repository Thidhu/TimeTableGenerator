Getting Started

1. Add teachers. 2. Add classes. 3. Add subject allocations. 4. Generate the timetable. 5. Check substitutions whenever a teacher is absent.

Teachers

Add, edit or remove teachers. There is no fixed limit, so the same system can be used for more than 100 teachers.

Classes

Add each class and the number of periods per day.

Subject Allocation

Choose the class, subject, teacher and number of periods per week. Add a shared resource such as ICT Lab if required.

Generate Timetable

The generator checks class availability, teacher availability, blocked periods, maximum daily workload and shared resources.

Current Clash Status

Generate or check a timetable to see the result.

Find a Substitute

Select the absent teacher, day and period. The system finds teachers who are free at that time and ranks suitable substitutes.

Backup Your School Data

Download your teachers, classes, allocations, timetable and substitutions. You can restore the same file later.
