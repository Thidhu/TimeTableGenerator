School Timetable & Substitution Manager

Auto-generate timetables, detect teacher clashes, and manage substitutions for small or very large schools.

Welcome

This first version is designed for your yearly timetable work. It can handle 100+ teachers because the data structure is not limited to a fixed number of teachers or classes.

1. Enter Data

Teachers, classes, subjects, weekly periods, unavailable periods and special resources.

2. Generate

The tool tries different arrangements and prevents a teacher or shared resource from being used twice in the same slot.

3. Substitute

Choose an absent teacher and period. The tool finds teachers who are free and ranks suitable substitutes.

Important: For very complicated school rules, a fully automatic timetable is a constraint-solving problem. This version gives a practical automatic generator and reports anything it cannot place, instead of silently creating clashes.

School Data

The data is stored as JSON so it can contain any number of teachers. You can save it and reuse it next year.

Data Format

The main information is:

{
  "school": "My School",
  "days": ["Mon","Tue","Wed","Thu","Fri"],
  "classes": [{"name":"IV","periodsPerDay":8}],
  "teachers": [{
    "name":"Teacher A",
    "maxDaily":6,
    "blocked":["Mon-P1","Fri-P8"]
  }],
  "allocations": [{
    "className":"IV",
    "subject":"Maths",
    "teacher":"Teacher A",
    "periodsPerWeek":9,
    "resource":""
  }]
}

For a shared ICT lab, put the same resource name, for example ICT Lab, in every allocation that needs it. The generator will prevent double use.

Generate Timetable

How the generator decides

It schedules difficult items first, checks class availability, teacher availability, blocked periods, shared resources and weekly requirements. It also penalizes unnecessary repetition of the same subject on the same day.
